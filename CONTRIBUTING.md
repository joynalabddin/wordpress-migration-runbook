# Contributing to the Blogger-to-WordPress Migration Runbook

Thank you for helping improve this educational migration resource. Contributions should make the runbook safer, clearer, more accurate, or more useful for authorized site owners, bloggers, developers, agencies, and support teams.

## Useful contribution types

- Correct a documentation error or unclear migration instruction.
- Add a general validation step that does not reveal private site details.
- Improve the worksheet, FAQ, accessibility, navigation, or terminology.
- Report a broken public link or outdated reference.
- Suggest a safe clarification about XML export, media, taxonomy, URLs, redirects, or launch monitoring.

## Do not publish sensitive material

Never include passwords, API keys, private analytics, Search Console exports, client names, private domains, personal data, payment information, or unpublished migration inventories in an issue, pull request, Discussion, screenshot, or commit. Describe the pattern generically and remove identifying details.

Do not submit instructions intended to access, modify, or disrupt a website without authorization. This repository is for legitimate migration planning, content transfer, URL preservation, validation, rollback, and defensive education.

## How to suggest an improvement

1. Explain the documentation problem or user need.
2. Describe the proposed change in general terms.
3. Include a safe reproduction or example only when it contains no private data.
4. Explain how the change improves clarity, safety, or usability.
5. Keep the change focused and avoid unrelated promotional edits.

For a project-specific migration, use a private authorized contact method rather than a public issue. For security concerns about this repository itself, use GitHub’s private security-reporting path when available.
